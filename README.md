# GlyEnzEA

Reaction-informed enrichment of enzyme-centered glycan sets from glycomics data.

This repository contains the code, source tables, frozen caches and outputs behind the manuscript
*GlyEnzEA: reaction-informed enrichment of enzyme-centered glycan sets from glycomics data*
(Himori K, Zhang B, Matsui Y; submitted to *Bioinformatics*, 2026). Everything needed to go from the
published source tables to the numbers, Figures 3-5 and the supplementary tables of the paper is here.

## What GlyEnzEA does

1. **Canonicalize.** Candidate glycan structures of each measured feature and the substrates and products of
   enzyme reaction rules (GlycoEnzDB, GlyGen) are written in one canonical topology representation (topoSeq).
2. **Match.** Each reaction rule is matched to each candidate structure by subgraph containment (VF2, igraph).
   A measured feature belongs to an enzyme's glycan set if any of its candidates matches any rule of that enzyme.
3. **Collapse and test.** Enzymes with identical glycan sets are merged into one hypothesis; each distinct set is
   tested once by over-representation analysis or preranked GSEA (fgsea), and all enzymes sharing the set are
   reported.

## Layout

| Directory | Contents |
|---|---|
| `R/` | structure parsing, canonical topology (topoSeq), VF2 substructure matching |
| `data/` | source tables: GlycoEnzDB and GlyGen exports, Nakano et al. 2019 mouse brain glycome (transcribed from the paper), Huang et al. 2021 HEK293 supplementary table, Glyco-Decipher glycan library |
| `cache/` | frozen GlyTouCan -> WURCS responses (GlyCosmos `gtcid2seqs`), so no network access is needed |
| `scripts/mouse/` | step1 reaction triplets, step2 glycome, step3 mapping + collapse, step3b library mapping, step4 ORA/GSEA, step4b curveball null |
| `scripts/robustness/` | minSize / nPermSimple / three-null sensitivity, Jaccard matrix, Table S1 |
| `scripts/hek293/` | Huang et al. 2021 seven knockouts: ID verification, adapter, mapping + GSEA, supplementary tables |
| `scripts/figures/` | Figures 3, 4 and 5 |
| `scripts/supplementary/` | Tables S1-S2 and Figure S1 |
| `output/` | analysis outputs (committed as the reference state; regenerated by `run_all.R`) |
| `provenance/` | frozen copies of the outputs, comparison script, run logs |
| `paper/figs/` | Figures 1-5 as submitted; `paper/supplementary/build/` Tables S1-S2 (CSV) and Figure S1 |

## Run

```sh
Rscript run_all.R                            # all stages, ~1 h (step3b library mapping is the slow part)
Rscript run_all.R mouse robustness figures   # mouse chain + sensitivity + Figures 3-5 (~6 min)
Rscript provenance/compare_frozen.R          # regenerated vs frozen outputs
```

R 4.3.2; package versions are in `renv.lock` (`renv::restore()`). Bioconductor packages: fgsea 1.28.0,
qvalue 2.34.0, ComplexHeatmap 2.18.0. `magick` needs ImageMagick with SVG support (Figure 4 inset).

Supplementary tables and Figure S1:

```sh
Rscript scripts/supplementary/build_tables.R            # Tables S1 (mouse) and S2 (HEK293) from output/
Rscript scripts/supplementary/figS1_column_examples.R   # Figure S1 -> paper/supplementary/build/figS1.html
```

## Analysis decisions

- **Mouse feature 10d is kept apart from 10a-10c.** 10d has no structure in Nakano et al. 2019 and increases in
  the knockout (0.5 % -> 2.1 %), whereas 10a-10c disappear; pooling it had diluted the 10a-c fold change (−1.9
  instead of −4.8). It is its own feature, unmapped and unranked. Details and the source rows:
  `data/Kizuka_MCP_2019/source_notes.md`; run log and seed check: `provenance/log_rerun_20261007_10d.txt`.
- Measured features with letter suffixes are pooled by number unless the paper keeps them distinct
  (9a/9b, 18a/18b, 19a/19bc); see `data/Kizuka_MCP_2019/source_notes.md`.
- HEK293 rows used from Huang et al. 2021 and their layout: `data/Huang_2021/source_notes.md`.
- The WURCS tree builder was corrected on 2026-05-19 (structures whose LIN block contains `|`, including
  sialylated N-glycans, had failed to convert), with further canonicalization fixes in August 2026. All reported
  results were produced with the corrected code; the library mapping (`scripts/mouse/step3b`) gives 10,936 records
  -> 8,412 with WURCS -> 8,098 valid -> 3,299 unique topologies, all mapped, 84 enzymes.

## Reproduction status

- Mouse chain step1 -> step4 rerun from `data/` + `cache/`: mapping matrix, 16 glycan sets and ORA identical to
  the frozen outputs; fgsea NES/P agree to 1e-4 (multilevel permutation). Three canonical topology strings differ
  from an earlier run in branch order only (membership unchanged); see `provenance/`.
- HEK293 chain 00 -> 02 rerun: NES, P and q for all 7 x 22 sets identical to the frozen outputs; Table S1 and the
  HEK293 supplementary tables byte-identical. Curveball null, minSize, three-null and Jaccard outputs identical;
  the nPermSimple sensitivity table varies by up to 0.006 in mean P (permutation noise).
- Glyco-Decipher library mapping (step3b, 84 min) reproduces the frozen 84 x 3,299 matrix exactly
  (`provenance/log_step3b_glycodecipher_mapping.txt`).
